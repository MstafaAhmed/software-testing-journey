#  Software Testing Journey

> Documenting my journey as a Software Testing Trainee at the Digital Egypt Pioneers Initiative (DEPI).

##  About

Welcome to my Software Testing Journey!

I recently started the **Software Testing track** in the **Digital Egypt Pioneers Initiative (DEPI)**. This repository is where I document everything I learn throughout the program, from software testing fundamentals to advanced automation testing.

My goal is to build a strong foundation in Quality Assurance (QA) by combining theoretical knowledge with hands-on practice. As I progress, I'll regularly update this repository with notes, assignments, test cases, bug reports, projects, and automation scripts.
